# v9: переход в музыке на «Поэтому важно»

Сценарий и памятка для чатов не менялись: `../v8/scenario_v8.md`, `../v8/chat_faq.md`. Изменён только монтаж музыки в сцене о кворуме (`src/audio.py`, KEEP).

**Было в v8.** Облегчённые такты с затихающим синтом склеивались встык с грувом из середины трека, и на «Поэтому важно» громко вступала ведущая партия.

**Стало.** Музыка идёт по пути самого трека: облегчение → затухание → нарастание → вход барабанов.
- Хэты уходят посреди фразы «Чтобы собрание могло…».
- Синт затухает к концу «…по площади помещений». Низ затухания и секунда цифровой тишины вырезаны, в удар нарастания ведёт короткий кроссфейд 0,12 с. В паузе музыка опускается не больше чем на 8 дБ.
- Удар нарастания звучит за 0,8 с до «Без кворума…». Внутри нарастания вырезаны такт и доля, стык стоит на пульсации.
- Барабаны вступают там, где их вводит сам трек, за 0,8 с до «Поэтому важно». Дальше грув трека и финальные такты без провалов.

Паузы в финале: около 1 с внутри сцены и около 2 с между сценами.

В `src/audio.py` у элементов KEEP появилось необязательное третье значение — длина кроссфейда в этот отрезок, в секундах.

Сборка — как в `../v8/README.md`.
