# Ответ на разбор v6

Разбор сверен с первичными документами: протокол от 18.07.2017, протоколы двух прошлых собраний, отчёт УК за 2025 год, проект решения текущего собрания. Ниже — что вошло в v7 и что нет.

## Принято

| Замечание | Что сделано в v7 |
|---|---|
| v05: «в прошлом году» в январе будет означать 2026-й | «По отчёту за 2025 год» |
| v05: не хватает средств, а не «тарифа» | «Средств по действующему тарифу на необходимый ремонт уже не хватает» |
| v05: вопрос 7 нужно оставить | Оставлен: «Новый договор управления и тариф снова вынесены на голосование — это седьмой вопрос бюллетеня». Добавлено «оплатить отдельно» — так взносы прямо отделены от тарифа |
| S5: полосы и доля водоснабжения | Полосы строятся по точным суммам, в подписях «≈», участок водоснабжения — 32 %, а не «треть». Кикер — «Отчёт УК за 2025 год» |
| S5, S16: проценты прошлых собраний | 24,41 % и 41,03 % «голосов», а не «проголосовали 24 %» |
| v09: неясное «платёж по нему» | Состав работ — отдельным предложением, условие «если решение примут» |
| v13: «если вы поддержите» читается как «платят только голосовавшие „за“» | «Если собрание утвердит все четыре взноса». Перезапись одной фразы |
| v16: «работы останутся без финансирования» шире фактов | «Без кворума собрание не сможет утвердить ни один из этих взносов» |
| S16: анимированная шкала похожа на текущий подсчёт | Шкала неподвижная, прошлые собрания — статичные отметки, строка «Работы не получат финансирование» заменена на «Без кворума взносы не утвердить» |
| v17: неясно, как сдать бюллетень 30–31 января | По проекту решения бюллетень можно опустить в ящик для показаний счётчиков в любой парадной. Добавлено в речь и в кадр. Почту не называем: письмо может не дойти к сроку |
| v17, S17: 31 и 29 января путаются | Сначала общий срок, потом способы, потом срок для офиса. На экране — разные строки, без анимации 31 → 29 |
| v04: «полумерами не обойтись» после «ремонтировали по частям» звучит как признание прошлых полумер; «уберечь от травм» — обещание безопасности | Фрагмент вырезается без перезаписи |
| S2: цепочка стрелок делает отключение воды причиной затопления | Ветвление: от «Прорыв на стояке» — две стрелки к двум последствиям |
| S7, S13, S18: «дальше начислений нет» шире темы | «Дальше начислений по взносам нет», в S7 — «без начислений по взносу» |
| S15: на экране потеряно условие обоснования | «Материалы обоснованно подешевели» |

## Не принято

| Замечание | Почему |
|---|---|
| Убрать «А дом не молодеет» и неотложность работ | Это прямая формулировка руководства. Смысл сохранён, канцелярское «не терпят отлагательств» заменено на «больше нельзя откладывать» |
| «Труб холодной воды» | Заказчик раньше отверг это выражение как неестественное. В ролике — «холодное водоснабжение» и «стояки и трубы в подвале» |
| Убрать метки [calm] и заглавные ударения | Это разметка для синтеза речи, которым пользуется заказчик. В субтитры она не попадает |
| v07: «закончатся после шестого платежа» заменить вставкой | «Платёж» здесь — ежемесячная часть взноса, на экране шесть сегментов начисления. Проект решения говорит о начислении «равными платежами в течение шести платёжных периодов», ролик ему не противоречит. Вставка в середину записанной реплики рискованна на стыке |
| v18: вырезать «Примите разумное решение —» | Финал одобрен руководством в v5, призыв не требует голосовать «за». Если руководство решит иначе, вырезка бесплатна |
| v16: заменить последнюю фразу на «Заполните бюллетень и передайте его…» | Записанная и одобренная фраза «важно, чтобы бюллетень сдал каждый собственник» не просящая и не требует голосовать «за». Повелительное наклонение дублировало бы v17 |
| S8: убрать формулу средней площади | Кадр одобрен, формула показывает, откуда взялись 41 м². Шрифт не мельче 56 px |
| S9–S12: нужны значения для остальных карточек | У каждой карточки свои значения; таблица добавлена в сценарий, чтобы не было вопроса |
| S16: подпись «Условный пример» | Шкала стала неподвижной: её больше не примут за текущий подсчёт, служебная подпись не нужна |

## Нужно подтвердить у руководства до выпуска
1. **Ящики в парадных 30–31 января.** Вынимают ли бюллетени до 18:00 воскресенья, засчитают ли опущенные в выходные. Ролик теперь направляет туда тех, кто не успел в офис.
2. **Перерасход 0,77 млн ₽ в 2025 году.** Источник покрытия — для ответов в чатах.
3. **Перераспределение между статьями.** В протоколе 2017 года такого права нет, нужно проверить договор управления.
4. **Демонтаж аварийного оборудования.** В вопросах 11 и 12 проекта решения записано: если решение не примут, аварийное оборудование демонтируют без установки нового. В ролик это не включено: прозвучит как давление. Добавить можно одной фразой в v16, если руководство захочет.
