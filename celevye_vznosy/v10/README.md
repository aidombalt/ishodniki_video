# v10: реплика о кворуме, музыка тише

Сценарий — `scenario_v10.md`, памятка для чатов — `../v8/chat_faq.md`.

- **S16.** Вместо «Без кворума собрание не сможет утвердить ни один из этих взносов» звучит «Без кворума собрание не сможет принять решение ни по одному из вопросов бюллетеня». Без кворума не принимается ни одно решение повестки, а не только взносы.
  - Новая фраза записана отдельным файлом `input/voice/v16b.mp3` и стоит на месте третьей фразы v16, без перезаписи всей реплики.
  - Надпись в кадре — «Без кворума решений не будет».
  - Фраза длиннее прежней на 0,9 с, поэтому нарастание перед «Поэтому важно» стало на долю длиннее (KEEP: 118–119¾, затем 120½). Паузы остались около 1 с.
- **Музыка тише.** Под речью она звучит на 16 LU ниже голоса, было 12,5 (`MUSIC_BELOW` в `src/audio.py`). Подъём музыки в паузах не изменился.
- **Сборка** — как в `../v8/README.md`. Голос: `../v5/input/voice` и `../v7/input/voice`, плюс `input/voice/v16b.mp3`.
- **Выход:** `output/celevye_vznosy_v10.mp4` (без субтитров, 6:19,7, −16,0 LUFS, пик −4,0 dBFS), `celevye_vznosy_v10.srt` (80 титров), раскадровки 640 и 390.
