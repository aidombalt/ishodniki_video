# Сборка v3

- `timing3.py` — раскладка озвучки, границы планов, точки синхронизации.
- `gfx3.py` — оформление: красные кружки/стрелки/подчёркивания от руки, текст с чёрной обводкой (Montserrat Black / Oswald, шрифты в `fonts/ttf`, лицензия SIL OFL), плашка НАТЛАНБЕТ, хромакей, размытая подложка для вертикальных клипов.
- `edit3.py` — монтаж и покадровый рендер (`stills <dir> t…` / `video t0 t1 out.mp4`).
- `audio3.py` — сведение: Local Forecast с паузами на вставках NPC, звук мемов, мем-эффекты.

Ожидает `PROJ` с `src/` (скриншоты, мемы, озвучка, музыка, `pot.webp`, распакованный `pack/Genshin_Meme_Pack`, `sfx/` с bruh / moye_moye / faah) и `work/V0..V3_cfr.mp4`. Для `gfx3.py` шрифты ищутся в `../fonts/ttf` относительно скрипта.
