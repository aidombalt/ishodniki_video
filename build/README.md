# Сборка ролика

Скрипты, которыми собран `Gospodin_Battles_1-2_v2.mp4`.

- `timing.py` — раскладка озвучки и общие точки синхронизации (картинка и звук берут тайминги отсюда).
- `gfx.py` — графика: рамки, плашки, вывеска НАТЛАНБЕТ, штамп, колпак, стрелки, волна.
- `edit.py` — монтажный лист и покадровый рендер (`stills <dir> t1 t2 …` для проверочных кадров, `video t0 t1 out.mp4` для куска).
- `audio.py` — сведение: озвучка, Local Forecast / Harvest Dawn с приглушением под голос, синтезированные эффекты.

Переменная `PROJ` указывает на папку с `src/` (скриншоты, мемы, озвучка, музыка, `pot.webp`)
и `work/` (исходники V0–V3, перегнанные в 30 к/с: `V0_cfr.mp4` … `V3_cfr.mp4`, 2400×1080).
Исходники в репозиторий не кладутся.
